📧 Email Settings (EmailJS)

EmailJS lets you send emails with PDF attachments directly from the browser — no server needed.
1. Create a free account at emailjs.com
2. Add an Email Service (Gmail, Outlook, etc.) and note the Service ID
3. Create a Template with variables: {{to_email}}, {{to_name}}, {{subject}}, {{message}}, {{attachment}} — note the Template ID
4. Copy your Public Key from Account → API Keys
5. Paste all three below and Save.
